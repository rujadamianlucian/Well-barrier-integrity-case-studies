This repository explores well-integrity problems through a series of small computational models inspired by failure cases described in An Introduction to Well Integrity. The aim is to connect physical well-barrier systems with numerical modelling techniques including transient pressure models, structural mechanics, inverse parameter estimation, and graph-based leak-path analysis.

The historical cases are used as engineering motivation rather than reconstructed directly. Where incident data are unavailable, synthetic parameters are used and clearly identified.

The focus is on understanding how a barrier can fail, what observable behaviour that failure produces, and what measurements could distinguish competing failure mechanisms.
